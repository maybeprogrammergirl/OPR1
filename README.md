# OPR1 – Základy programování v Javě

Školní repozitář pro předmět **OPR1** (Objektové programování 1).

## Obsah repozitáře

- [`cviceni/`](cviceni/) – úlohy a cvičení z hodin
- [`ukoly/`](ukoly/) – domácí úkoly a projekty

## Požadavky

- **Java JDK 17** nebo novější
- IDE dle vlastního výběru (doporučeno: [BlueJ](https://www.bluej.org/), [IntelliJ IDEA](https://www.jetbrains.com/idea/), [VS Code](https://code.visualstudio.com/))

## Jak spustit program

1. Zkompilujte zdrojový soubor:
   ```bash
   javac NazevTridy.java
   ```
2. Spusťte program:
   ```bash
   java NazevTridy
   ```
